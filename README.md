# Information Security Labs

This repository contains laboratory assignments completed for the **Information Security** course.

Each lab focuses on a core security or system concept and is documented with explanations,
commands, configurations, and examples.  


## 📂 Repository Structure

### Introductory & System Labs


- **Lab01** – Comprehending UNIX terminal commands  
- **Lab02** – Custom UNIX-based commands and shell scripting  
- **Lab03** – Toy shell (Python-based)  
- **Lab04** – Phishing (educational mockup and security awareness)  
- **Lab05** – User management in Linux  
- **Lab06** – File permissions in Linux  
- **Lab07** – Crontab and task automation in Linux  

Each lab folder typically contains:
- `README.md` – lab description and explanations  
- `.txt` or script files – examples or implementations  

---

### Advanced & Security-Focused Labs
- **Lab08** – Vim Editor  
  Working with Vim modes, navigation, editing, and commands.

- **Lab09** – Package Management  
  Linux package concepts, APT commands, and installing software such as nginx.

- **Lab10** – Configuring NGINX  
  NGINX configuration, virtual hosts, and reverse proxy using `proxy_pass`.

- **Lab11** – Installing Packages from Source  
  Installing software from source using `make`, `cmake`, and Git-based workflows.

- **Lab12** – Brute-Force Attacks  
  Overview of brute-force attack techniques and defensive understanding using Hydra
  (documented demonstration).

- **Lab13** – Key Logger (Ethical & Safe Demonstration)  
  Demonstrates how locally stored logs can be **eventually sent to an API server**
  using safe log-shipping concepts, without implementing spyware behavior.

---

## 🛠 Environment Notes

- **Operating System:** Windows  
- **Version Control:** Git & GitHub  

Some Linux-specific features (e.g., `sudo`, `crontab`, `chown`, `apt`) are documented
conceptually when not supported natively on Windows.
Where applicable, alternative approaches or explanations are provided.

---

## 🎯 Learning Outcomes

Through these labs, the following topics were covered:

- UNIX/Linux command-line usage  
- Shell scripting and automation  
- File permissions and ownership  
- User and group management  
- Task scheduling with cron  
- Package management and software installation  
- Web server configuration (NGINX)  
- Brute-force attack concepts and defenses  
- Ethical considerations in security tooling  

---

## ⚠️ Ethics & Responsibility

All security-related labs are completed with a **defensive and ethical focus**.
Potentially harmful techniques are explained conceptually or demonstrated in a
safe manner to avoid real-world misuse.
