# Lab 08 – Vim Editor

## Environment
- OS: Windows
- Terminal: Git Bash
- Editor: Vim

## Steps

1. Create a file
touch file.txt

2. Open file in Vim
vim file.txt

3. Insert text
i
some text
more text
even more text

4. Delete a line
ESC
dd

5. Delete all content
ESC
:%d

6. Save file
ESC
:w

7. Quit Vim
:q
:wq

## Extra Vim Commands
- gg : go to top
- G : go to bottom
- yy : copy line
- p : paste
- u : undo
- /word : search

## Conclusion
This lab demonstrates basic Vim usage in Git Bash on Windows.
