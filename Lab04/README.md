# Lab 04 – Phishing 

Name: Fatemeh Ebrahimi  
Course: Information Security  

## Overview
This lab demonstrates phishing concepts in a safe and ethical way using:
- a non-operational login page mockup
- an awareness email template
- a local demo server to display pages

## Ethics Note (Important)
- No credentials are collected, stored, or transmitted.
- No phishing emails are sent to real recipients.
- The goal is awareness and understanding, not exploitation.

## Files
- instagram-login.html: UI mock login page (no data submission)
- email-template.html: awareness training email template
- server.py: local demo server to view pages (no storage)
- mail.py: placeholder (sending disabled)
- login_data.txt: not used for collection (contains a safety note)
